MotrLabs Procedure

  1. Photo belt routing before removal.
  2. Release tensioner 14mm. Remove belt.
  3. Spin pulleys — MD368209 must spin silent, no play. If gritty >0.5mm lateral — dead.
  4. Replace both guides — torque 44-48 Nm.
  5. New belt: Crank -> AC -> Idler1 -> Alt -> Idler2 (MD368209) -> Tensioner -> PS.
  6. Run 2 mins, re-check, listen.
  7. If throttle body cleaned same job: battery disconnect 10 mins, idle relearn AC OFF then ON.
