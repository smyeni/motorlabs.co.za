MotorLabs Procedure — MotorLove style — 3 Belt System

  1. Photo all 3 belt routings before removal — 6G72 3-belt routing is easy to mix.
  2. Alternator belt: Loosen alternator pivot + tensioner MD368209 (14mm). Remove belt. Spin MD368209 — must be silent, no lateral play >0.5mm.
  3. AC belt: Loosen AC tensioner, remove. Spin its pulley.
  4. PS belt: Loosen PS pump + tensioner, remove. Spin.
  5. Replace all 3 pulleys if rough + 3 new belts. Torque tensioner bolt ~44-48 Nm for MD368209.
  6. Tension: Alternator belt ~5-7mm deflection mid-span, AC ~5mm, PS ~5-7mm. Don't over-tighten — kills alternator bearing.
  7. Run 2 mins, re-check tension, listen.
  8. If throttle body cleaned same job: disconnect battery 10 mins, idle relearn AC OFF then AC ON.

Guide / Tensioner pulley MD368209: 44-48 Nm | Belt deflection: 5-7mm | Alternator pivot: 45 Nm
